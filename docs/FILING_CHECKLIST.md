# Provisional Patent Filing Checklist (Educational)

**This is not legal advice.** Confirm all requirements with current USPTO guidance or a registered practitioner.

## Before Filing

- [ ] Review `specification/PROVISIONAL_PATENT_SPECIFICATION.md` for technical accuracy against the actual source code.
- [ ] Complete inventor name(s) and residence.
- [ ] Complete correspondence address.
- [ ] Decide entity status (micro / small / large) and prepare any required certifications.
- [ ] Optionally prepare simple drawings (system block diagram, request-flow sequence).
- [ ] Confirm that all matter you wish to claim priority to is present in the specification and supporting materials.

## USPTO Form PTO/SB/16 (Provisional Application Cover Sheet)

Required information typically includes:

- Inventor name(s) and residence
- Title of the invention
- Correspondence address
- Entity status
- List of attachments (specification, drawings if any, sequence listing if applicable)
- Signature / electronic authentication

Obtain the current form from the USPTO website (Patent Center / forms).

## Filing Steps

1. Create or sign in to a USPTO.gov account.
2. Open Patent Center → File a new application → Provisional.
3. Upload the written description (and drawings if any).
4. Complete the cover sheet.
5. Pay the applicable fee (micro-entity provisional fee was $65 in the 2026 schedule—verify current amount).
6. Submit and retain the filing receipt / application number.

## After Filing

- [ ] Record the application number and filing date.
- [ ] Calendar the 12-month deadline for a non-provisional utility application claiming benefit of the provisional.
- [ ] The provisional itself is not examined and does not mature into a patent.
- [ ] Consider whether further development, commercialization analysis, or practitioner review is warranted before converting.

## Risk Note

USPTO statistics indicate a high abandonment rate for pro-se (self-filed) applications that proceed to examination. A provisional is a lower-stakes first step, but the quality of the disclosure determines the strength of any later non-provisional that claims its priority date.
